# Catálogo geográfico de Colombia

Nombres e identificadores de municipios extraídos exclusivamente de las tablas City y Department del archivo dump-apicolombia-202606142128.sql de https://github.com/Mteheran/api-colombia, commit a69f8b6dafb0e3708149b1546fe68d23ae4ce6d6. Consulta: 2026-10-30. Licencia MIT adjunta.

Incluye 1123 registros y 33 agrupaciones departamentales (incluye Bogotá como distrito separado). Los IDs pertenecen a API Colombia; no son códigos DIVIPOLA. Esta es una copia local de referencia, no una certificación del directorio administrativo vigente. No se ejecuta el dump ni se incluyen descripciones u otras tablas. No se hacen consultas externas en tiempo de ejecución.

Las urbanizaciones son un catálogo independiente administrado por el propietario de la aplicación; esta fuente geográfica no contiene conjuntos residenciales. Prato de la Toscana en Sabaneta fue confirmado por el usuario. No se dispone todavía de un listado completo verificado de urbanizaciones de Sabaneta.
